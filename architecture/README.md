# Interactive Archify architecture

Architecture embeds `static/architecture.html`, generated by the official [tt-a1i/archify](https://github.com/tt-a1i/archify) project, version 3.2.0 at revision `a4065941f12be7967436261d9934784e381d423c`. It is the real standalone Archify viewer, with component/source inspection, search, zoom, route/reach exploration, themes and exports. No hosted Archify service receives repository data or credentials at runtime; the generated HTML includes its own fonts/scripts. The existing AgentSim login protects the HTML and its embedded view.

`agentsim.architecture.json` is the editable architecture input. Its repository identity pins the application source at the recorded revision; every component cites committed source ranges. It documents the system and its conditional execution paths, not currently active connections or live agent activity. The saved team configuration remains below the interactive viewer; use Watch & run for real execution activity.

Run `./scripts/build-architecture.sh` from a development checkout with Node.js 18+, Git, Python 3 and a supported Chromium installation. The script uses an isolated ignored upstream checkout pinned to the exact revision above (or `ARCHIFY_PACKAGE` for a checkout at that revision); it does not install or replace global skills. It runs Archify's complete finalize pipeline: validate, deliver, provenance check and browser check, then copies only the passing standalone HTML into `static/`. Detailed receipts stay in ignored `work/architecture-build`; `verification.json` records the source/output hashes and passing gates without machine-specific paths. Update source evidence when runtime code changes; never put provider credentials, login hashes or operational databases into the candidate.

Upstream software is Apache-2.0 with historical MIT portions. Preserve the files under `licenses/` when distributing the embedded runtime. The generated HTML also contains notices for its embedded font. These third-party licenses apply to the Archify runtime, not a transfer of authorship of AgentSim's source-backed diagram or a replacement for the application's WABIX attribution.

The generated HTML is preserved byte-for-byte from the verified Archify output and marked generated in `.gitattributes`; upstream whitespace is retained so its verification hash remains valid. Authored project files retain normal whitespace checks.
